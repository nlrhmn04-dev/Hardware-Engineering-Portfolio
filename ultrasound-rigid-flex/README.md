# Ultrasound Rigid-Flex PCB

Rigid-flex PCB redesign for ultrasound transducer to improve signal integrity and reduce signal path length.

## Overview
Redesigning existing FPC ultrasound transducer connection, due to the lack of shielding and noise from parasitic inductance, as a rigid-flex PCB, improving SNR and signal integrity. 

## Problem Statement
Current 10 cm FPC introduces signal integrity issues:
- SNR degradation from cable length
- Poor shielding
- Parasitics

## Proposed Solution
Rigid-flex PCB design to:
- Reduce signal path to ~3cm
- Improve shielding and ground plane design
- Optimize impedance control
- Implement proper flex-to-rigid transitions

## Design Goals
- **Target**: >10dB SNR improvement
- Controlled impedance traces
- Minimize reflections
- Improve current ultrasound imaging 

## Status
Currently in design phase. Characterizing existing FPC performance and designing rigid-flex replacement.

## Tools
- KiCad (with flex support)
- Oscilloscope
