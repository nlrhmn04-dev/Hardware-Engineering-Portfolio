## Projects

### [EMG Analog Front-End](./emg-analog-frontend)
4-layer mixed-signal PCB for high-precision EMG signal acquisition.
- **Tools**: KiCad, ADS1299, ESP32, LTspice
- **Specifications**: 100 dB CMRR, <5 µVrms noise, Mixed Signal Design

### [Neonatal Wearable Sensor PCB](./neonatal-wearable-pcb)
2-layer FPCB integrating temperature and SpO2 sensors for neonatal imaging research.
- **Tools**: KiCad, TMP117, MAX30102, C++, I2C
- **Specifications**: <10ms timing accuracy, ±0.2mm mechanical tolerance

### [Velocity-Based Training Device](./velocity-training-device)
Real-time barbell velocity measurement system using IMU sensor fusion.
- **Tools**: ESP32, MPU6050, Python, FFT analysis
- **Specifications**: <8% velocity error, custom DSP filtering

### [Ultrasound Rigid-Flex PCB](./ultrasound-rigid-flex) *(In Progress)*
Rigid-flex PCB redesign for ultrasound transducer to improve signal integrity.
- **Tools**: KiCad, Signal Integrity Analysis
- **Status**: Design phase
